# SpaceKrafters OS

Mobile-first interactive demo and product documentation for SpaceKrafters' interior operations platform.

## Live Demo

https://thermh.github.io/Spacekrafters-crm-demo/

## Product Scope

- Phase 1: Interior Operations Management
- Phase 2: Performance and Accountability
- Phase 3: Financial Control and Budget Management
- Phase 4: Procurement and Vendor Management

## Documentation

Open the [documentation index](docs/README.md) for the complete product and implementation pack.

The repository contains:

- Product requirements
- End-to-end business workflow
- Information architecture
- Roles and permissions
- Screen specifications
- Database design
- API specification
- Notifications and SLA rules
- Reports and dashboards
- Development roadmap

## Current Status

The deployed HTML file is an interactive mobile concept. It demonstrates the planned modules and navigation, but it is not a production backend application.

The documentation folder is the primary reference for UI/UX design, estimation and full-stack development.
