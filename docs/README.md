## Scope

The current product scope is specific to SpaceKrafters and covers four connected areas:

- Phase 1: Interior Operations Management
- Phase 2: Performance and Accountability
- Phase 3: Financial Control and Budget Management
- Phase 4: Procurement and Vendor Management

## Product Boundary

The system is intended to manage interior project operations, approvals, documents, budgets, procurement and employee performance.

The following are not part of the initial scope:

- Full statutory accounting
- GST filing
- Payroll processing
- Bank reconciliation
- Inventory valuation
- Client portal
- Vendor portal
- Native mobile application

The current HTML application is a mobile-first interactive concept. These documents define the target product for design and development.
